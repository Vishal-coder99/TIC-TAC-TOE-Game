# 🎮 Tic-Tac-Toe Game

A simple, interactive, and responsive **Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript**.

This project was created to practice **JavaScript logic, DOM manipulation, event handling, and responsive web design** while building a fun browser-based game.

## ✨ Features

- 🎮 Two-player gameplay
- ❌ Player X and ⭕ Player O
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔄 Restart / Reset game
- ⚡ Fast and interactive gameplay
- 📱 Responsive design
